# Zero Repository Skill

Use this skill when working on the Zero repository.

Read and follow the root `AGENTS.md` file first. It is the canonical public agent guide for Zero and covers project intent, development rules, operational model, security research standards, and public repo hygiene.

When creating, reviewing, or tuning custom scan campaigns, also read `docs/CLI.md` and `docs/CUSTOM_CAMPAIGNS.md`. They cover the CLI surface, expected parameter patterns, staged rollout guidance, path-probe considerations, target sources, and custom Webanalyze/Nuclei template loading rules.

Keep changes aligned with Zero's core purpose: durable recon, fingerprinting, passive intelligence, and targeted validation campaigns over authorized assets with structured state, deduplication, and low-noise reporting.
