# Zero Repository Skill

Use this skill when working on the Zero repository.

Read and follow the root `AGENTS.md` file first. It is the canonical public agent guide for Zero and covers project intent, development rules, operational model, security research standards, and public repo hygiene.

When creating, reviewing, or tuning custom scan campaigns, also read `docs/CUSTOM_CAMPAIGNS.md`. It contains the expected parameter patterns, staged rollout guidance, path-probe considerations, and custom Webanalyze/Nuclei template loading rules.

Keep changes aligned with Zero's core purpose: durable, focused vulnerability-analysis campaigns over authorized bug bounty assets with structured state, deduplication, and low-noise reporting.
